# 13 — JANSAHAY UI/UX Design System

## 1. Design Philosophy
- **Citizen Centric**: Clean, dignified, modern design tailored for ease of use across diverse digital literacy levels.
- **Visual Clarity**: Premium typography (Inter / Outfit), high-contrast visual cues, warm government gold/emerald/indigo accents, and responsive mobile-first views.
- **No Bureaucratic Jargon**: All complex states are accompanied by plain-language descriptions and clear action badges.

## 2. Key Screen Blueprints
1. **Public Discovery Hub**: Search bar, categorized service tiles, eligibility helper modal, and instant AI chat widget.
2. **Citizen Application Wizard**: Step 1 (Personal & Eligibility Verification) $\to$ Step 2 (Personalized Document Checklist) $\to$ Step 3 (Quarantined Upload with scan feedback) $\to$ Step 4 (Declaration & Submit) $\to$ Step 5 (Acknowledgement with Case ID).
3. **Interactive Case Tracker**: Visual milestone stepper, downloadable certificate badge upon resolution, and targeted re-upload widget if marked `ACTION_REQUIRED`.
4. **Officer Scoped Workspace**: Multi-role quick switcher for demo reviewers (`Verification Officer`, `Department Officer`, `Approving Officer`), queue filtering, side-by-side document scrutiny viewer, and explicit workflow action buttons (`VERIFY`, `REQUEST_CORRECTION`, `FORWARD`, `APPROVE`, `REJECT`).
