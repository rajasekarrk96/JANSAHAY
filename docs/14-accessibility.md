# 14 — JANSAHAY Accessibility & Inclusive Design

## 1. WCAG 2.1 AA Compliance Target
- **Contrast Ratios**: Minimum 4.5:1 for normal text, 3:1 for large headers and interactive buttons.
- **Keyboard Navigation**: Full keyboard tab navigation, visible focus rings (`ring-2 ring-indigo-500`), skip-to-content links.
- **Screen Reader Support**: Semantic HTML tags (`<header>`, `<main>`, `<nav>`, `<section>`, `<article>`), ARIA labels on modals, file upload dropzones, and status tags.
- **Multilingual / Indic Readiness**: Architecture designed with standardized i18n key-value structures ready for Hindi and regional language expansion.
